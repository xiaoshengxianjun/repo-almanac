# 项目志 · RepoAlmanac

项目志是一个本地桌面应用。首次启动显示空工作区，点击「打开项目」选择自己的项目文件夹，即可浏览文件体积、从业务操作追到源码，或根据依赖清单和运行环境查看升级建议。

![项目志的默认工作区](docs/preview.png)

## 本地运行

推荐使用 Node.js 24 LTS 和 npm 开发，也支持 Node.js 22.13 及以上的 22.x 版本。首次安装及获取 Electron 运行时需要联网。

```sh
npm ci
npm start
```

`npm test` 运行回归测试，`npm run format:check` 检查代码格式。`npm run build` 执行 TypeScript 严格类型检查并构建界面。`npm run package` 构建当前系统和架构的桌面应用，输出到 `release/`。

构建使用 TypeScript 7 检查类型。源码分析器通过微软的 `@typescript/typescript6` 兼容包读取语法树，用于定位业务函数、请求和配置项。[TypeScript 版本兼容说明](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#running-side-by-side-with-typescript-60)

## 体验路径

1. 点击「打开项目」并选择本地代码目录，扫描完成后进入「项目概览」。
2. 选择检测到的业务操作，点击链路节点打开源码。展开完整流程可按顺序查看已定位的路由、事件、请求和处理函数。
3. 在概览的「文件构成」切换「按数量」和「按体积」。进入「文件分布」后，点击目录色块或选择子目录下钻，可按相对路径搜索文件，包括零字节文件。
4. 在「升级建议」查看当前项目命中的依赖约束、迁移步骤和证据文件。点击「导出报告」可保存 Markdown。
5. 点击顶栏项目名称左侧的返回箭头，关闭项目并回到首页。重启后仍停留在首页。应用保留最近一次扫描，再次选择同一目录会恢复该索引。点击「重新扫描」可读取最新改动。「应用设置」中的「清除项目索引」可删除缓存。

## 支持范围

- 扫描任意可读目录中的文件元数据，以 SQLite 存储当前完整快照。应用读取配置和源码，默认跳过符号链接目标。
- 使用 TypeScript 和 Vue 编译器分析静态页面、事件、函数调用及 HTTP 请求。可解析的本机 Vite 代理与 Express 监听端口可用于确认后端归属；动态地址、外部后端或多个候选服务会保留待确认项。
- npm 适配器支持 v1/v2/v3 锁文件。首个内置历史规则用于评估 Vite 4 到 5 的迁移，并非当前最新版本推荐。公共查询仅发送用户选定的已知公共包名称。
- AI 为可选功能。可设置支持聊天补全协议的本地服务或云服务；发送前可查看完整证据摘要。规则结论保存在本地，模型不可更改兼容性判断。
- 深度解析对单个源文件设置 1 MiB 上限，对清单设置 24 MiB 上限，每次最多解析 8000 个文件、共 100 MiB。所有可读普通文件仍计入文件分布。扫描详情中可查看覆盖范围。
- 扫描通过读取文件完成，不会运行所选项目的脚本或安装其依赖。

## 工程结构

| 目录 | 职责 |
| --- | --- |
| `desktop/` | Electron 窗口、IPC 与扫描任务调度。模型请求和 Markdown 报告各有独立模块 |
| `engine/` | SQLite 文件索引、语法树分析、业务关系定位和升级规则 |
| `src/` | React 界面。`main.tsx` 挂载应用，`App.tsx` 管理工作区状态，`desktop.ts` 定义界面可调用的 IPC 接口 |
| `src/pages/`、`src/dialogs/` | 四个分析页面，以及搜索、源码、模型设置等弹窗 |
| `src/components/`、`src/styles/` | 图表、共用控件和界面样式 |
| `shared/` | 主进程和界面共同使用的 AI 证据格式，预览和发送均从这里生成 |
| `tests/` | 文件扫描、源码定位、升级判断和报告内容的回归测试 |
| `assets/`、`scripts/` | 品牌图标和桌面应用打包脚本 |

完整范围和验收目标见[第一版需求与技术方案](docs/v1-product-and-technical-design.md)。
